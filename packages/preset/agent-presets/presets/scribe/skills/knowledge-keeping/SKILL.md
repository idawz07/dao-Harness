# Knowledge keeping

1. Prefer durable paths and short abstracts over dumping full file bodies.
2. Ingest lasting sources with `reference_add` (path, url, or title+text); search with `reference_search`; navigate with `reference_index`; fetch or remove with `reference_get` / `reference_list` / `reference_remove`.
3. Cluster related sources and note contradictions.
4. Flag stale or duplicated material for the orchestrator.
5. Keep the index navigable: source → summary → next action.
