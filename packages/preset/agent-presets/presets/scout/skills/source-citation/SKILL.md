# Source citation method

1. Prefer primary sources over summaries.
2. Record every claim with a URL or absolute file path and a short verbatim quote.
3. Separate confirmed facts from inference.
4. If search returns nothing useful, say so — do not fill gaps with guesses.
5. End with a short "Sources" list the orchestrator can hand to the user.
