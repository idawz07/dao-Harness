# Doc conventions

1. English only. Current-state prose — no change narration.
2. One physical line per paragraph in Markdown docs that the gates enforce.
3. Link the owning decision or package README; do not duplicate facts.
4. Prefer concrete names (response fields, ESM exports) over vague abstractions.
5. Update the nearest README or note in the same change as the behavior.
