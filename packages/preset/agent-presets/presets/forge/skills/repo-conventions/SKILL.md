# Repo conventions

1. Match the surrounding file's imports, naming, and test style.
2. Prefer editing an existing module over adding a parallel one.
3. Keep comments local to non-obvious contracts; do not narrate control flow.
4. Update the owning tests with the behavior change.
5. Report the files touched and the check commands you ran.
